⬡ Rendering logic driven by a runtime frame.

📍 run::RunRender

A runtime or driver builds a RunFrame and calls run_render to let a renderer project a scene or app state into a presentation artifact.

The output may borrow from the renderer or scene. It should not borrow from the backend frame context.

This trait defines rendering only. It does not define logical progression or final presentation.
