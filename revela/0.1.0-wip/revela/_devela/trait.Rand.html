Expand description

🎲 Infallible source of raw random data.

📍 num/prob/rand::Rand

Rand is implemented automatically for every RandTry source whose error type is Infallible.

Determinism, reproducibility, cryptographic suitability, weakness, external state, and blocking behavior are described by the source characteristics inherited from RandTry.

fn rand_below(&mut self, upper: u64) -> u64

Returns a uniformly random integer in 0..upper.

Uses rejection sampling to avoid modulo bias.

fn rand_range(&mut self, low: u64, high: u64) -> u64

Returns a uniformly random integer in low..high.

§Panics

Panics if low >= high.

fn rand_roll(&mut self, sides: u64) -> u64

Rolls a fair die with a number of sides.

Returns a value in 1..=sides.

fn rand_shuffle<T>(&mut self, slice: &mut [T])

Shuffles the elements of the slice in place.

Uses the Fisher–Yates algorithm.

fn rand_choose_reservoir<I, F>( &mut self, iter: I, valid: F, ) -> Option<<I as IntoIterator>::Item> ⓘ
where I: IntoIterator, F: FnMut(&<I as IntoIterator>::Item) -> bool,

Chooses one valid item using reservoir sampling.

This is uniform over all valid items and uses one pass.

fn rand_choose_scored<I, F>( &mut self, iter: I, valid: F, ) -> Option<<I as IntoIterator>::Item> ⓘ
where I: IntoIterator, F: FnMut(&<I as IntoIterator>::Item) -> bool,

Chooses one valid item using random scores.

Each valid item receives a random score. The highest score wins. Ties are resolved uniformly.

Dyn Compatibility§
