🎲 ⊆ Semantic qualities of a random source.

📍 num/prob/rand::RandQualities

📦 size_of::<RandQualities>() == 1 bytes / 8 bits ⚗️Option<T> ❗🟰 T

These qualities describe source behavior and suitability independently of its output width, state size, and fallibility.

The absence of a quality means that property is not claimed. In particular, a source may be neither cryptographic nor known to be weak.

Named constants

pub const DETERMINISTIC: RandQualities

1 The output stream is determined by the source’s current state.

pub const REPRODUCIBLE: RandQualities

1 The same explicit seed material can recreate the same stream.

pub const CRYPTOGRAPHIC: RandQualities

1 The source is intended for cryptographic use.

pub const EXTERNAL: RandQualities

1 The source depends on state outside its own value.

pub const MAY_BLOCK: RandQualities

1 The source may block while producing random data.

pub const GENERATOR_WEAK: RandQualities

1 The source has known generator-side weaknesses, such as poor statistical behavior, short period, or limited state capacity.

pub const ENTROPY_WEAK: RandQualities

1 The source draws unpredictability from weak or low-entropy material.
