🔩 🔌 An Espressif USB Serial/JTAG controller.

Provides byte-oriented polling access to the CDC-ACM serial endpoint.

Unlike a UART, this transport has no baud rate or framing configuration: bytes are exchanged as USB packets through the controller’s endpoint FIFO.

📍 mcu/esp32::EspUsbSerialJtag
