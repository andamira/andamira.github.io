🔩 🛠️ Classic Arduino Nano board namespace.

📍 board/avr::BoardArduinoNano

📦 size_of::<BoardArduinoNano>() == 0 bytes

The board is based on McuAtmega328p.

The analog header labels A0..=A7 correspond to ADC channels 0..=7. ADC access itself is provided by the associated McuAtmega328p.

See also:

  • Arduino Nano documentation
  • pinout
  • datasheet
