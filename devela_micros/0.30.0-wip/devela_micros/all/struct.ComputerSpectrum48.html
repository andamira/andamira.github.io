🔩 🛠️ Sinclair ZX Spectrum 48K computer namespace.

📍 computer/zx/spectrum::ComputerSpectrum48

📦 size_of::<ComputerSpectrum48>() == 0 bytes

The machine uses a ProcessorZ80 running nominally at 3.5 MHz. Processor-level operations and instruction timing live there; Spectrum memory, display, ULA, keyboard, and machine timing live here.

§Operations

Display:

  • set_pixel and toggle_pixel modify individual bitmap pixels.
  • write_bitmap and write_bitmap_byte provide raw bitmap access.
  • fill_bitmap and clear_bitmap operate on the complete 6144-byte bitmap.
  • write_cell_attribute and fill_attributes modify the 32×24 attribute area.

ULA and input:

  • set_border changes the border colour.
  • write_ula writes the complete border/MIC/EAR state.
  • key_pressed reads one key.
  • read_keys reads the complete keyboard matrix.

Raw display-memory access requires unsafe_mmio. Z80 I/O operations require a Z80 target with unsafe_hint.

§Addressing

bitmap_offset translates the Spectrum’s non-linear bitmap layout, while attribute_offset addresses the linear 32×24 attribute grid.

§References

See the Sinclair Wiki’s ZX Spectrum 16K/48K overview and the World of Spectrum 16K/48K technical reference.

§Timing

The 48K Spectrum runs its Z80A nominally at 3.5 MHz.

A video frame contains 312 scanlines of 224 T-states each, for 69,888 T-states per frame and an actual frame interrupt frequency of approximately 50.08 Hz.

The ULA generates the frame-synchronous interrupt used by many Spectrum programs for game and display timing.

§Memory

The 48K Spectrum maps 16 KiB of ROM at 0x0000..=0x3FFF followed by 48 KiB of RAM at 0x4000..=0xFFFF.

RAM at 0x4000..=0x7FFF is contended: while the display is being generated, the ULA has priority for shared RAM accesses and can temporarily pause the Z80.

See Contended memory.

§ULA

The Uncommitted Logic Array handles display generation, keyboard and tape I/O, border colour, beeper output and the frame-synchronous interrupt.

Its conventional I/O address has low byte 0xFE. Reads use the high address byte to select keyboard half-rows; writes control border colour, MIC, and the beeper.
