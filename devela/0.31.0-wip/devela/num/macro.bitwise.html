macro_rules! bitwise {
    (

    /* Single-bit operations */

     test $bits:expr; bit $index:expr) => { ... };
    (set $bits:expr; bit $index:expr) => { ... };
    (clear $bits:expr; bit $index:expr) => { ... };
    (toggle $bits:expr; bit $index:expr) => { ... };
    (

    /* Mask predicates */

     any $bits:expr; mask $mask:expr) => { ... };
    (all $bits:expr; mask $mask:expr) => { ... };
    (

    /* Hacker's bit tricks */

     clear_lowest $bits:expr) => { ... };
    (isolate_lowest $bits:expr) => { ... };
    (isolate_trailing $bits:expr) => { ... };
    (

    /* Inclusive bit ranges: feature-selected default. */

     mask $T:ty; $start:tt ..= $end:tt) => { ... };
    (extract $bits:expr; $start:tt ..= $end:tt) => { ... };
    (insert $bits:expr, $value:expr; $start:tt ..= $end:tt) => { ... };
    (

    /* Range backend selection: available per invocation. */

     @inline $($range:tt)+) => { ... };
    (@methods $($range:tt)+) => { ... };
}

⅀ ▫️ A mnemonic vocabulary of bitwise operations, with selectable range backends.

📍 num/fin::bitwise!

This macro requires no capability feature or Bitwise implementation. It operates on unsigned integer primitives; all bit indices are zero-based. Operations return values without mutating the inputs and evaluate each argument once.

Range operations use an inline backend by default, or delegate to Bitwise methods when the bitwise feature is enabled. The implementation can also be selected per invocation, without changing the operation’s semantics:

  • bitwise![@inline mask u8; 2..=5] forces primitive expressions.
  • bitwise![@methods mask u8; 2..=5] requires the bitwise feature.

The same prefixes work with extract and insert. Selection and validation take place within the macro; neither backend is required to validate ranges.

The extended Bitwise namespace and BitOps trait require the bitwise feature.

§Single bits

  • test, set, clear, toggle interpret the last argument as a bit index.

§Masks

  • any, all interpret the last argument as a bit mask.
  • An empty mask makes any false and all true.

§Hacker’s bit tricks

  • clear_lowest: remove the lowest set bit (zero stays zero).
  • isolate_lowest: isolate the lowest set bit (zero stays zero).
  • isolate_trailing: isolate the lowest unset bit (all ones yields zero).

§Inclusive ranges

  • mask T; START..=END: construct a T mask covering the range.
  • extract BITS; START..=END: shift the selected bits down to bit zero.
  • insert BITS, VALUE; START..=END: replace the region, truncating VALUE.

For range forms, both bounds must be within the integer width and START <= END. Invalid ranges panic in all build modes. Full-width ranges are supported without an overflowing shift.

Single-bit forms follow Rust’s ordinary shift behavior for invalid indices (debug overflow checks; do not pass an out-of-range index).

Range bounds must be a single token tree (a literal, identifier, or a parenthesized expression), matching the syntax of set! and bitfield!.

§Corresponding Bitwise methods

These are semantic counterparts. With the bitwise feature, the three range operations delegate to these methods by default, but @inline can override that. The links use the u8 implementation; all six unsigned primitives are supported.

bitwise! armBitwise method
test BITS; bit Nis_set
set BITS; bit Nset
clear BITS; bit Nunset
toggle BITS; bit Nflip
any BITS; mask Mis_set_mask
mask T; START..=ENDmask_range
extract BITS; START..=ENDget_value_range
insert BITS, VALUE; START..=ENDset_value_range

all checks an arbitrary mask and has no direct Bitwise equivalent; is_set_range instead checks a contiguous range. The three hacker idioms likewise have no direct counterparts. Unlike the unchecked Bitwise range methods, bitwise! range arms panic for invalid ranges in all build modes.

§Examples

use devela::bitwise;

let bits = 0b1010_0000_u8;
assert!(bitwise![test bits; bit 7]);
assert_eq!(bitwise![set bits; bit 0], 0b1010_0001);
assert_eq!(bitwise![clear bits; bit 7], 0b0010_0000);
assert_eq!(bitwise![toggle bits; bit 5], 0b1000_0000);

assert!(bitwise![any bits; mask 0b1000_0001]);
assert!(!bitwise![all bits; mask 0b1000_0001]);

assert_eq!(bitwise![mask u8; 3..=6], 0b0111_1000);
assert_eq!(bitwise![extract 0b1011_0110_u8; 1..=4], 0b1011);
assert_eq!(bitwise![insert 0b1000_0001_u8, 0b101_u8; 1..=3], 0b1000_1011);
