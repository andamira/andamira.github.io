7//!
8//! This module describes how logical UI state is prepared for presentation.
9//! It provides frame-local visual records, drawing instructions, broad output
10//! forms, and measures for projecting logical space into concrete units.
11//!
12//! [`UiView`] associates a resolved [`UiId`] with its [`UiRect`],
13//! [`UiLayer`], and [`UiViewFlags`].
14//!
15//! ```text
16//! UiView
17//! ├── UiId
18//! ├── UiRect
19//! ├── UiLayer
20//! └── UiViewFlags ── HIDDEN | CLIPPED | OPAQUE
21//!
22//! UiDrawList ── borrowed as ──> UiDrawListView
23//!
24//! logical layout
25//! ├── UiDensity + UiRound ──> physical pixels
26//! └── UiCellMetric ─────────> discrete cells
27//! ```
28//!
29//! [`UiViewForm`] classifies broad presentation families without selecting a backend:
30//!
31//! ```text
32//! UiViewForm
33//! ├── Cell
34//! ├── Graphic
35//! ├── Document
36//! └── Message
37//! ```
38//!
39//! These forms identify materially different ways to present UI state.
40//! They do not require every application to support every form, nor
41//! do they prescribe one common rendering strategy for all of them.
42//!
43//! This module remains incomplete. Its current types establish shared
44//! visual records and projection measures without fixing how complete
45//! views, form-specific profiles, or backend presenters must be assembled.
46//!
47//! # Boundaries
48//!
49//! - Resolved identity comes from [`ui::frame`][crate::ui::frame].
50//! - Logical regions come from [`ui::layout`][crate::ui::layout].
51//! - Semantic meaning belongs to [`ui::semantic`][crate::ui::semantic].
52//! - General drawing and media resources belong to [`media`][crate::media].
53//! - Concrete host surfaces and backend presentation belong at system and backend boundaries.
54//!
55//! This implies no retained view tree, scene graph, styling system,
56//! universal draw model, or fixed rendering pipeline.
57//!
58//! [`UiId`]: crate::UiId
59//! [`UiRect`]: crate::UiRect
60//
