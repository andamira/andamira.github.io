1// devela/src/index.rs
2//
3//! *A development substrate of coherence.*
4//!
5//! devela is a general-purpose Rust library
6//! built from small, reusable abstractions.
7//!
8//! It provides foundations without assuming more than a problem needs.
9//! Allocation, runtime choice, platform support, and other capabilities
10//! are added explicitly, while simpler forms remain useful on their own.
11//!
12//! Common abstractions are shared across domains rather than repeated
13//! for each particular use. The modules below organize the library
14//! by the kinds of problems they address.
15//
