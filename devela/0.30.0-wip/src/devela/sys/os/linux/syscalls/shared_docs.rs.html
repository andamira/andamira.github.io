12_DOC_SYS_READ = r#"Performs a [read] syscall.
13
14Reads up to `count` bytes from file descriptor `fd` into `buf`.
15
16This is a low-level ABI wrapper. Prefer [`Linux::read_fd`] for normal use.
17
18[read]: https://www.man7.org/linux/man-pages/man2/read.2.html
19
20# Safety
21- `fd` must be a valid open file descriptor.
22- `buf` must be valid for writes of `count` bytes.
23- `buf` must remain valid for the duration of the syscall.
24- The caller must handle partial reads, `EINTR`, `EAGAIN`, and end-of-file.
25"#;

27_DOC_SYS_WRITE = r#"Performs a [write] syscall.
28
29Writes up to `count` bytes from `buf` into file descriptor `fd`.
30
31If a write is interrupted by a signal handler before any bytes are written, then
32the call fails with `EINTR`. If it is interrupted after at least one byte has
33been written, the call succeeds and returns the number of bytes written.
34
35This is a low-level ABI wrapper. Prefer [`Linux::write_fd`] or
36[`Linux::write_fd_all`] for normal use.
37
38[write]: https://www.man7.org/linux/man-pages/man2/write.2.html
39
40# Safety
41- `fd` must be a valid open file descriptor.
42- `buf` must be valid for reads of `count` bytes.
43- `buf` must remain valid for the duration of the syscall.
44- The caller must handle partial writes, `EINTR`, `EAGAIN`, and zero progress.
45"#;

126_DOC_SYS_DUP2 = r#"Performs a [dup2] syscall.
127
128Duplicates `oldfd` to the descriptor number `newfd`, closing `newfd` first if it
129is already open.
130
131This is a low-level ABI wrapper. Use only when exact descriptor-number control

133
134[dup2]: https://www.man7.org/linux/man-pages/man2/dup2.2.html
135
136# Safety
137- `oldfd` must be a valid open file descriptor.
138- `newfd` must be either a valid descriptor number or equal to `oldfd`.
139- If `newfd` is open and differs from `oldfd`, it may be closed by this call.
140- On success, `newfd` becomes an owned duplicate that must eventually be closed,
141  unless ownership is deliberately transferred elsewhere.

281_DOC_SYS_GETRANDOM = r#"Performs a [getrandom] syscall.
282
283Obtains random bytes from the kernel random source.
284
285[getrandom]: https://www.man7.org/linux/man-pages/man2/getrandom.2.html
286
287# Flags
288
289- `GRND_RANDOM` = 0x001
290
291  Use the `/dev/random` source instead of the `/dev/urandom` source.
292
293- `GRND_NONBLOCK` = 0x002
294
295  Return immediately if no data is available.
296
297- `GRND_INSECURE` = 0x0004
298
299  Write random data that may not be cryptographically secure.
300
301# Safety
302- `buf` must be valid for writes of `buflen` bytes.
303- `buf` must remain valid for the duration of the syscall.
304- `flags` must contain only flags accepted by `getrandom`.
305- The caller must handle short reads, blocking behavior, and retry policy.
306"#;
