22/// `TextScanner` provides incremental, allocation-free traversal over a borrowed
23/// text source, exposing byte-oriented operations suitable for building parsers.
24/// It Owns traversal state and delegates stateless string/slice operations
25/// to [`Str`][] and [`Slice`] where possible.
26///
27/// # Methods
28///
29/// - Construction and views:
30///   - [new](#method.new).
31///   - [from_bytes](#method.from_bytes).
32///   - [slice](#method.slice).
33///   - [slice_str](#method.slice_str)
34///     ([*unchecked*](#method.slice_str_unchecked)<sup title="unsafe method">⚠</sup>).
35///   - [rest](#method.rest).
36///   - [take_rest](#method.take_rest).
37///
38/// - Cursor state and range construction:
39///   - [pos](#method.pos).
40///   - [mark](#method.mark).
41///   - [remaining_len](#method.remaining_len).
42///   - [advance](#method.advance).
43///   - [is_eof](#method.is_eof).
44///   - [range_from](#method.range_from).
45///
46/// - Predicate-driven scanning adapters:
47///   - [eat_if](#method.eat_if).
48///   - [skip_while](#method.skip_while).
49///   - [take_while](#method.take_while).
50///
51/// - Byte inspection and exact consumption:
