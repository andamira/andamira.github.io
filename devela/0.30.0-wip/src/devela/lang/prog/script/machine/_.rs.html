7//!
8//! The scripting machine is a small resumable execution kernel.
9//!
10//! [`ScriptMachine`] owns suspended execution state but neither the program
11//! being executed nor the world affected by it. This keeps program storage,
12//! execution state, and external authority independent.
13
14//! ## Execution
15//!
16//! Direct and hosted execution share the same machine state and transition
17//! protocol. They differ only in who resolves external calls.
18//!
19//! [`ScriptMachine::step`] and [`ScriptMachine::run`] return external
20//! interaction as [`ScriptOutcome::HostCall`]. The caller may inspect the
21//! contained [`ScriptCall`], perform the requested effect, and resume the
22//! machine with [`ScriptMachine::complete_call`].
23//!
24//! [`ScriptMachine::step_with`] and [`ScriptMachine::run_with`] resolve the
25//! same interaction through a [`ScriptHost`] instead.
26//!
27//! ```txt
28//! program: &[ScriptOp<R>]
29//!          │
30//!          ▼
31//!    ScriptMachine
32//!          │
33//!       step / run
34//!          │
35//!          ▼
36//!    ScriptOutcome
37//!      ├─ Yielded
38//!      ├─ Returned
39//!      ├─ BudgetExhausted
40//!      └─ HostCall(call)
41//!              │
42//!       resolve externally
43//!              │
44//!              ▼
45//!      complete_call(value)
46//!              │
47//!              └──────► resume
48//!
49//! step_with / run_with:
50//! HostCall ──► ScriptHost::call ──► value ──► resume
51//! ```
52//!
53//! ## Reference payloads
54//!
55//! `R` is the machine's opaque reference payload type. It is carried by
56//! [`ScriptValue::Ref`] but is never interpreted or validated by the machine.
57//! Typical payloads are compact IDs or generational handles into caller-owned state.
58//!
59//! `R` can remain stored after its external target becomes invalid.
60//!
61//! Direct execution can resolve these references explicitly. Hosted execution
62//! passes the same values through [`ScriptHost`].
63//!
64//! # Errors
65//!
66//! A failing operation leaves machine state unchanged.
67//! External effects are not rolled back.
68//
