✨ 🗃️ ➰ An example set of independent optional links.

📍 data/topol/link::LinkExample

📦 size_of::<LinkExample>() == 4 bytes / 32 bits ⚗️Option<T> ❗🟰 T

Generated by link!.

It demonstrates two links sharing one compact target representation and a third independently represented link.

§Methods

  • Construction: new.
  • Representation: from_parts, into_parts.
  • Primitive conversion: from_prim, into_prim, try_from_usize.
  • State: is_empty.
  • Per-link access: get_<field> (_prim, _usize), has_<field>.
  • Per-link mutation: set_<field> (_prim), clear_<field>, with_<field>, without_<field>.
