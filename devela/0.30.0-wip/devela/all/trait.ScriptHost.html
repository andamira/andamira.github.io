Expand description

𝕃 A host capability boundary for resolving scripted operations.

📍 lang/prog/script/machine

ScriptMachine::step_with and ScriptMachine::run_with resolve host calls through this trait. Direct execution may instead return ScriptOutcome::HostCall for explicit resolution by the caller.

R is the opaque reference payload carried by machine values.

Arguments are supplied in stack order, with the earliest argument first. Every successful call returns exactly one machine value; ScriptValue::Nil represents a call with no meaningful result.
