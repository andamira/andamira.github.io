§Native libraries

Source

pub fn has_lib(lib: &str) -> bool

Returns whether a native library is discoverable.

Uses pkg-config/pkgconf first, then falls back to direct file search in common platform library paths.

Source

pub fn emit_flag_if_lib(flag: &str, lib: &str) -> bool

Emits flag if a native library is discoverable.

The flag is emitted as-is. It may be a normal cfg flag or a devela reflective flag such as ffi_xcb_shm··.

Returns whether the flag was emitted.

§Features

If the feature __disable_native_libs is enabled then this always returns false.
