Cross-cutting code and macro utilities.
util::{assert, cfg, debug, synth, token} ◉

This module collects small, cross-cutting facilities for authoring, checking, inspecting, and transforming Rust code.

assert checks assumptions, cfg controls compilation, and debug assists diagnostics. synth constructs and composes Rust code, while token operates on the token, fragment, identifier, and literal material from which macros work.

Facilities with a clearer domain or semantic home belong there instead; util is not a general catch-all namespace.
