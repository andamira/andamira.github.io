Retained data stores and retrieval semantics.
store::{arena, key, pool} ◉

Extends: std::{collections}

Storage governs how values remain and are recovered.

A store retains values across operations and defines how they are inserted, retrieved, reclaimed, and potentially reused.

Layout describes arrangement and occupancy. Identity distinguishes one entity from another. Storage determines the lifecycle of the retained values themselves.

  • Arenas advance monotonically and reclaim storage collectively.
  • Keyed stores recover values through keys and lookup structures.
  • Pools reclaim and reuse individual slots.
