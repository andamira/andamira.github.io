Semantic value categories and composable data forms.
value::{tuple} ◉

Values describe the semantic forms carried by data independently of storage, identity, and canonical raw representation.

ValueKind classifies broad semantic categories, while ValueKind4 provides its compact universal band. NoData represents absence and Oneof represents a fixed choice among alternatives.

Exact canonical representation belongs to data::word, arrangement and retention belong to data::layout and data::store.
