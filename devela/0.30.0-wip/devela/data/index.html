Structural abstractions for organizing and manipulating data.
data::{access, codec, history, id, layout, store, topol, value, word} ◉

Extends: std::{array, collections, hash, iter, vec}

The data tree separates several independent concerns:

  • Access determines how values are reached and traversed.
  • Codecs transform or derive data representations.
  • Identification distinguishes values through identities and contextual references.
  • Layout determines how values are positioned and grouped.
  • History records how values originate and evolve.
  • Storage governs how values remain and are recovered.
  • Topology describes connectivity, adjacency, and ordered relations.
  • Values provide the semantic forms carried by these structures.
  • Words expose exact canonical raw representations of copyable values.
